	\subsubsection{Normalizado}
	Una vez se ha realizado el balanceo de los datos, se procederá a realizar la normalización del conjunto de datos de entrenamiento y de prueba para evitar que los algoritmos tengan un sesgo y aprendan mejor unas características que otras, buscando que estos datos sigan una distribución normal lo máximo posible. Para ello, hay dos tipos de normalización que se pueden aplicar, "MinMaxScaler" y "StandardScaler", MinMaxScaler viene representado por la siguiente formula:
	
	\begin{equation*}
		xi=\frac{xi-min(xi)}{max(xi)-min(xi)}
	\end{equation*}
	
	MinMaxScaler se caracteriza por poder transformar una característica para que quede, habitualmente entre un rango fijo de 0 y 1, permitiendo reescalar las características de un conjunto de datos y conservar la forma de la distribución. Esta técnica difiere un poco con respecto a StandardScaler, que es la otra técnica de normalizado que se va a probar a usar. Esta técnica tiene como objetivo modificar todos los valores del conjunto de datos de tal forma que tengan un valor de media 0 y un valor de desviación típica de 1, tratando de aproximar los datos a la distribución normal estándar, lo máximo posible. La formula que aplica es la siguiente:
	
	\begin{equation*}
		xi=\frac{xi-\mu i}{\sigma i}
	\end{equation*}
	
	Finalmente, el código que se ha utilizado para el MinMaxScaler es el siguiente:
	\begin{lstlisting}[style=mypython, caption={Normalización mediante MinMaxScaler}, label={lst:División-del-conjunto-de-datos-entrenamiento-prueba}]
		
		scaler = preprocessing.MinMaxScaler()
		
		X_train = scaler.fit_transform(X_train) 
		# aplica los calculos sobre el conjunto de datos de entrenamiento para escalarlos 
		X_test = scaler.transform(X_test) 
		# aplica los calculos sobre el conjunto de datos de prueba para escalarlos
		
		
	\end{lstlisting}
	
	Y, para el caso de StandarScaler es el siguiente:
	\begin{lstlisting}[style=mypython, caption={Normalización mediante StandarScaler}, label={lst:División-del-conjunto-de-datos-entrenamiento-prueba}]
		
	scaler = preprocessing.StandardScaler()

	X_train = scaler.fit_transform(X_train)

	\subsubsection{Análisis de componentes principales (PCA)}
	Una vez se ha llevado a cabo la normalización de los 3 conjuntos de datos (original, original con undersampling y original con oversampling) se procederá a realizar el PCA para buscar conjuntos de ejes de coordenadas en los que algunas de las dimensiones no sean necesarias para estos 3 conjuntos de datos.
	
	Para ello se utilizará el algoritmo \textit{PCA} implementando la librería \textit{scikit-learn}. Inicialmente utilizaremos el algoritmo sin parámetros para analizar el porcentaje de varianza de todos los componentes utilizando \textit{explained\_variance\_ratio\_}, que devuelve una lista en este caso, con 22 elementos, donde cada elemento de la lista indica el porcentaje de variabilidad que representa ese componente.Además, sumando estos porcentajes de variabilidad se consigue saber la varianza acumulada correspondiente al número de componentes utilizados cumpliendose siempre que la suma de todos los elementos de la lista dará 1 como resultado. El código que se ha utilizado para obtener la varianza y la varianza acumulada es el siguiente:
	\begin{lstlisting}[style=mypython, caption={Varianza y varianza acumulada de los componentes}, label={lst:División-del-conjunto-de-datos-entrenamiento-prueba}]
		
		mypca = PCA()
		mypca.fit(X_train)
		
		mypca.explained_variance_ratio_	#	muestra todos los componentes de la lista
		
		mypca.explained_variance_ratio_.sum()  # Suma todos los elementos de la lista 
		
		print("\n Varianza que aporta cada componente:")
		variance = mypca.explained_variance_ratio_
		print(variance)
		
		print("\n Varianza acumulada:")
		acumvar = variance.cumsum()
		
		for i in range(len(acumvar)):
		print(f" {(i+1):2} componentes: {acumvar[i]:.8f} ")		
	\end{lstlisting}
	
	Conocidos estos porcentajes de varianza acumulada se pueden representar en una gráfica para poder ver claramente cual es la cantidad de componentes que se debería utilizar para hacer PCA.
	
		\begin{figure}[H]
		\centering
		\includegraphics[width=1.1\textwidth]{Figuras/GraficaVarianzaAcumulada.png}
		\caption{Gráfica de varianza acumulada }
		\label{Mennekes}
	\end{figure}
	
	Aquí se puede observar como a partir del decimoquinto componente la varianza acumulada tiene un valor muy cercano al 95\%, esto quiere decir que los datos que se van a perder se corresponden con el 5\% de los datos totales. Es por ello que se decide tomar un total de 15 componentes para realizar el cálculo del PCA, ya que con menos componentes las pérdidas de datos se consideran demasiado grandes todavía. Para confirmar que el \textit{Projection loss} no es demasiado alto, se utilizará el siguiente código que nos devolverá su valor:
		\begin{lstlisting}[style=mypython, caption={Projection loss para 15 componentes}, label={lst:División-del-conjunto-de-datos-entrenamiento-prueba}]
		
		mypca15 = PCA(n_components=15)
		mypca15.fit(X_train)
		values_proj15 = mypca15.transform(X_train)
		
		X_projected15 = mypca15.inverse_transform(values_proj15)
		loss15 = ((X_train - X_projected15) ** 2).mean()
		
		print("Projection loss (15 components): " + str(loss15)) 
		
	\end{lstlisting}
	
	Obteniendo finalmente un valor de \textit{Proyection loss} del 5.07\% reduciendo las dimensiones del conjunto de 22 a 15, por lo que se considera aceptable.

	\subsubsection{Algoritmo de clasificación por vecindad k-nn}
	Este será el primer algoritmo de clasificación que utilicemos, este es muy característico debido al empleo de vecinos, a la hora de determinar un dato perteneciente a una clase, se estima que aquellos datos pertenecientes a la misma clase se encontrarán próximos en el espacio de representación, siendo estos los "vecinos" representados en el código por la letra k. Las pruebas que se realizarán serán para un rango de k de entre 5 y 100 tratando de buscar un valor que nos de buenos resultados. Además, se intentará que este valor de k no sea ni muy bajo ni muy alto ya que  un valor de k alto da lugar a un modelo muy estable y poco sensible al ruido pero puede perder detalles y un valor de k bajo que proporciona un modelo flexible y que se adapta muy bien a variaciones y detalles, pero que es muy sensible al ruido.
	\\

	Para realizar pruebas de una forma cómoda y comprobar cual es el mejor caso se ha empleado un bucle "for" que nos devuelva el valor de exactitud del modelo y el tiempo de entrenamiento empleado para cada caso. Además, también se realizará el cálculo de exactitud y tiempo de entrenamiento 5 veces para cada valor de k y, posteriormente,  nos quedaremos con el mejor caso de los 5 calculados:
	
	\begin{lstlisting}[style=mypython, caption={Código del algoritmo de clasificación k-nn}, label={lst:División-del-conjunto-de-datos-entrenamiento-prueba}]
		
		Score = np.zeros(95)
		Posicion = np.zeros(95)
		Time = np.zeros(95)
		for i in range(5,100):
		k = i   # Numero de vecinos
		Score_ind=np.zeros(5)
		Posicion_ind=np.zeros(5)
		Time_ind=np.zeros(5)
		for u in range (1,6):
		ini = time.time()
		# Creamos nuestra instancia de nuestro algoritmo KNN con K vecinos
		neigh = KNeighborsClassifier(n_neighbors = k)
		neigh.fit(X_train,y_train)
		y_predict_knn = neigh.predict(X_test)
		
		Time_ind[u-1] = (time.time() - ini)*1000
		Score_ind[u-1] = neigh.score(X_test, y_test)
		Posicion_ind[u-1] = i
		Time[i-5] = np.max(Time_ind)
		Score[i-5] = np.max(Score_ind)
		Posicion[i-5] = i
		print(f"Tiempo entrenamiento para k={i}  = {Time[i-5]} ms") 
		print("Exactitud media obtenida con k-NN para k={i}: ".format(i=i), neigh.score(X_test, y_test))
		
		Valor_maximo = np.max(Score)
		Tiempo_min = np.min(Time)
		print(f"El valor maximo de exactitud es de: {Valor_maximo}")
		print(f"Y esta situado en la posicion: {Score.argmax()+1}")
		print(f"El valor minimo de tiempo es de: {Tiempo_min}")
		print(f"Y esta situado en la posicion: {Time.argmin()+1}")
		
	\end{lstlisting}
	
	Con este código obtendremos de resultado final el caso para el valor máximo de exactitud y el caso para el tiempo mínimo de entrenamiento, para el modelo sin balancear y sin PCA el caso para mayor precisión se da en el rango de entre k=5 y k=13, mientras que el tiempo de entrenamiento mínimo se dió para k=7, pero para poder estudiar más en detalle todos los casos y ver claramente que opción escoger, se mostrarán las gráficas para cada conjunto de datos a estudiar las cuales servirán como guía:
